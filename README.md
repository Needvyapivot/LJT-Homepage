# LJT-Homepage

Personal academic homepage of **Junteng Liu**, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template and hosted on GitHub Pages.

The site contains:

- **About (home page):** personal details, education, honors and awards, research experience, publications, research interests, and contact information.
- **Publications:** a structured list of publications.

## Local development

See the [Academic Pages documentation](https://github.com/academicpages/academicpages.github.io) for instructions on running the site locally with Jekyll.
